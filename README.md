# Searching Algorithm Visualizer

This project is a web-based implementation of different searching algorithms developed as part of the Design and Analysis (DA) PBL project.

## 🚀 Features
- User-friendly website interface
- Enter custom array values
- Search any element dynamically
- Multiple searching algorithms
- Instant result display
- Beginner-friendly project structure

## 🔍 Algorithms Implemented
- Linear Search
- Binary Search
- Jump Search
- Interpolation Search
- Exponential Search

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Project Objective
The objective of this project is to understand the working, efficiency, and practical implementation of different searching algorithms through an interactive web interface.
